# 🌦️ WeatherNow

A simple and responsive **Weather App** built using **HTML, CSS, and JavaScript** that provides real-time weather information for any city or place.

The application uses the **Open-Meteo API**, so **no API key, account, or signup is required**. Users can search for a city and view important weather statistics such as temperature, humidity, wind speed, pressure, visibility, cloud cover, sunrise, sunset, and weather conditions.

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Current temperature
* 🌡️ Feels-like temperature
* 💧 Humidity
* 💨 Wind speed
* 🧭 Wind direction
* 🌡️ Atmospheric pressure
* 👁️ Visibility
* ☁️ Cloud coverage
* 🌅 Sunrise time
* 🌇 Sunset time
* 🌤️ Dynamic weather icons
* 📍 Current location weather
* 🕐 Local date and time
* ⚡ Loading indicator
* ⚠️ Error handling
* 📱 Fully responsive design
* 🔑 No API key required

## 🛠️ Technologies Used

* **HTML5** - Structure of the application
* **CSS3** - Styling, layout, animations, and responsive design
* **JavaScript** - Application logic and API integration
* **Open-Meteo API** - Real-time weather data
* **Open-Meteo Geocoding API** - City search and location data

## 🚀 How to Use

### 1. Download or Clone the Project

Download the project files or clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Open the project folder in **VS Code**.

### 3. Run the Application

No installation or setup is required.

Simply open:

```text
index.html
```

in your web browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

### 4. Search for a City

Enter a city name in the search bar.

For example:

```text
Pune
Mumbai
Delhi
London
Tokyo
New York
Paris
Dubai
```

Click **Search** or press **Enter**.

The application will fetch and display the current weather information.

### 5. Use Current Location

Click the **My Location** button and allow location access in your browser.

The application will use your current coordinates to retrieve the weather for your location.
